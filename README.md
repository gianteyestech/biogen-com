# Biogen Pharma — E-Commerce & Medical Supply Platform

A Next.js e-commerce platform built for **Biogen Pharma** — delivering certified pharmaceuticals, precision surgical instruments, eye care loupes, and hospital furniture across West Africa (The Gambia & Sierra Leone) and internationally.

## Tech Stack
* **Framework**: Next.js 16 (App Router + Turbopack) & React 19
* **Styling**: Tailwind CSS v4 & Lucide Icons
* **Database**: MariaDB / MySQL via Hostinger (`u564667558_getbgdb`) with local JSON fallback
* **Media Storage**: Hostinger Storage Endpoint (`https://assets.idealdryfruit.com/bg_upload.php`)
* **Email & SMTP**: Namecheap / cPanel Webmail (`business176.web-hosting.com:465`)

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```

## Admin Dashboard
Access the administrative portal at `/admin` to manage:
* Medical Product Catalog & Category taxonomies
* Live Customer Orders & Status updates
* Hero promotional banners & Announcements
* Site configurations, contact lines & payment gateways
* Live Customer Inquiries & Chat Threads
